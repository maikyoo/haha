System Overview

ORION-1 is a dual-node, low-latency autonomous ground reconnaissance rover designed for indoor tracking, environmental safety profiling, and real-time remote telemetry. Built around a decentralized embedded computing architecture, ORION-1 offloads high-bandwidth media processing from real-time motor and sensor control loops, operating over an independent ad-hoc Wi-Fi Access Point (192.168.4.x).

Operator Dashboard HTML5 / WebSockets / Telemetry UI Connects via HTTP controls and WebSockets to the Core Control Node (192.168.4.1:80) and via MJPEG video stream to the Video Node (192.168.4.50:80).

  • Initialize serial communication at 115200 baud.
  • Initialize DHT sensor, attach radar servo to pin 25, set MQ-2 pin to INPUT.

The rover provisions an isolated IEEE 802.11 b/g/n network with DHCP IP leasing from 192.168.4.2 to 192.168.4.254. Zero third-party cloud brokers or external internet lines are utilized.
